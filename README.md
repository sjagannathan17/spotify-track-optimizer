# Spotify Album Track Analysis & AI Chatbot

Analyzed 188,000+ Spotify tracks to determine optimal album sequencing, then built AI chatbot for personalized recommendations.

## Key Findings

**Quality Gap Effect:** Moderate gaps (10-20 points) → +18 album boost (R²=0.42)

**Genre Strategy:** Pop +22 points from front-loading; Rock no benefit

**Artist Tier:** First track explains 79% variance for emerging artists vs 31% for superstars

## Tools

**Analysis:** Python (Pandas, Scikit-learn), Regression Analysis

**Chatbot:** React, JavaScript, Tailwind CSS
